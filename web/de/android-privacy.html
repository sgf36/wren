Datenschutz für Android

Zuletzt aktualisiert am 17. August 2026

Die Kurzfassung

Die App hat keine Konten und keine Analyse. Ihre Screenshots und alle Dateien, die Sie importieren, werden auf Ihrem Telefon gelesen und niemals hochgeladen. Das Einzige, was sie speichert, ist eine zufällige Kennung für Ihr Gerät, und das nur, wenn Ihnen ein kostenloser Code gegeben wurde und Sie sich entscheiden, ihn einzugeben – dies ist auch der einzige Grund, aus dem sie einen eigenen Server kontaktiert.

Diese Website ist eine separate Angelegenheit: Sie verwendet Google Analytics, und nur dann, wenn Sie den Hinweis bei Ihrem ersten Besuch akzeptieren. Wenn Sie ablehnen, werden keine Cookies gesetzt.

Was Wren erfasst

Nichts, mit einer Ausnahme, und nur wenn du sie wählst: Wird ein kostenloser Code eingegeben, gehen dieser Code und eine zufällige Kennung für diese Installation an einen von Wren betriebenen Server. Sonst wird nichts über dich erfasst, gespeichert oder weitergegeben. Kein Konto, keine Anmeldung, keine Analyse, keine Werbekennung, keine Absturzberichte.

Gibst du nie einen Code ein — und fast niemand tut das, weil Codes an namentlich bekannte Personen gehen —, kontaktiert Wren überhaupt keinen eigenen Server.

Deine Screenshots und importierte Dateien

Werden auf dem Telefon gelesen und nie hochgeladen. Die Texterkennung läuft mit einem Modell, das in der App selbst steckt, also funktioniert das Lesen eines Screenshots auch mit abgeschaltetem Netz, und das Bild verlässt dein Gerät nie. Dasselbe gilt für eine CSV-, GPX-, KML- oder Takeout-Datei, die du importierst.

Was dein Gerät verlässt und wohin es geht

Zwei Dinge, und keines davon ist ein Screenshot.

Das erste ist der Name eines Ortes und die Stadt, die du bestätigt hast. Aus „Dishoom Shoreditch“ eine Koordinate zu machen heißt, eine Karte zu fragen, und Androids eigener Geocoder antwortet über das Netz — auf den meisten Telefonen ist das Google, nach Googles Datenschutzerklärung, genau wie bei jeder App, die eine Adresse nachschlägt. Mehr geht nicht mit, und überhaupt nichts geht, bevor du eine Suche anstößt.

Die Stadt ist eine, die du in der App gewählt hast. Wren fragt nie, wo dein Telefon ist — es gibt bewusst keine Standortberechtigung. Es fragt nur, wo ein genannter Ort ist.

Das zweite ist ein kostenloser Code und eine zufällige Kennung, gleich beschrieben.

Kostenlose Codes

Manche Menschen erhalten einen Code, der kostenpflichtige Funktionen ohne Zahlung freischaltet. Wird ein Code eingegeben, gehen zwei Dinge an einen vom Entwickler betriebenen Cloudflare Worker: der Code und eine zufällige Kennung für diese Installation. Das Paar wird gespeichert, damit ein Code einmal und nicht noch einmal verwendet werden kann — und das ist der einzige Grund, warum überhaupt ein Server beteiligt ist, denn ein Telefon kann nicht wissen, dass ein Code bereits auf einem anderen Telefon eingelöst wurde.

Die Kennung wird von Wren erzeugt und ist aus nichts abgeleitet: nicht aus deiner Android-ID, nicht aus der Werbekennung, aus nichts an der Hardware oder deinem Konto. Sie kennzeichnet diese Installation und sonst nichts. Deinstallieren entfernt sie, eine Neuinstallation bekommt also eine neue Kennung.

Eine kleine Zahl von Codes gewährt zusätzlich administrativen Zugang zur Code-Konsole des Entwicklers. Nur diese werden etwa einmal täglich beim Server erneut bestätigt, damit ein solcher Code zurückgezogen werden kann. Eine erneute Bestätigung sendet dieselben zwei Dinge und sonst nichts. Ein gewöhnlicher Code wird einmal geprüft, beim Eingeben, und danach nie wieder.

Wird ein Code abgelehnt, wird die ursprüngliche IP-Adresse für sich allein bis zu einer Stunde festgehalten, damit der Endpunkt nicht mit Rateversuchen überzogen werden kann. Sie wird nicht neben dem Code oder der Kennung gespeichert, bei einem erfolgreichen Code gar nicht erst, und sie wird automatisch gelöscht.

Deine Liste an eine andere Karten-App geben

Die Liste wird als Datei auf deinem Telefon geschrieben und der App übergeben, die du auswählst. Diese Übergabe ist lokal: nichts wird hochgeladen, und Wren ist nicht mehr beteiligt, sobald die andere App die Datei hat.

Google My Maps ist die Ausnahme, die man nennen sollte. Wren speichert die Datei über Androids eigenen Speicherdialog und öffnet dann google.com/maps/d/ in deinem Browser. Was danach passiert, ist dein Browser, in deiner eigenen Google-Sitzung — Wren lädt nichts hoch und kann es nicht sehen.

Berechtigungen

Genau eine: Internetzugriff, gebraucht für die Ortssuche und, falls du einen eingibst, für den Code. Kein Standort, keine Kamera, keine Kontakte und kein Zugriff auf Dateien außer denen, die du ihr über die Systemauswahl reichst.

Was auf deinem Gerät gespeichert wird

Falls du einen kostenlosen Code eingelöst hast, die signierte Antwort, die das bestätigt. Damit kann Wren deinen Zugriff offline prüfen. Und die Liste der Orte, an der du gerade arbeitest, bis du sie veröffentlichst oder leerst.

Das ist gewöhnlicher App-Speicher auf deinem Telefon, abgedeckt von der Verschlüsselung deines Geräts. Wren zu löschen löscht sie.

Instagram und andere Apps

Wren verbindet sich nicht mit Instagram, TikTok oder einem anderen Dienst. Es hat keinen Zugriff auf Ihre Konten dort und liest, durchsucht oder lädt nichts von dort herunter. Es liest nur Screenshots, die Sie selbst aufgenommen und mit ihm geteilt haben.

Kinder

Wren richtet sich nicht an Kinder und erhebt von niemandem, unabhängig vom Alter, personenbezogene Daten.

Ihre Rechte

Nach der britischen DSGVO und der EU-DSGVO haben Sie Anspruch auf Zugang, Berichtigung, Löschung, Einschränkung, Widerspruch und Übertragbarkeit bezüglich der über Sie gespeicherten personenbezogenen Daten.

Wenn Sie noch nie einen kostenlosen Code eingegeben haben, speichert Wren überhaupt nichts über Sie, sodass es praktisch nichts gibt, worauf zugegriffen, was berichtigt oder gelöscht werden könnte. Falls doch, besteht der einzige Eintrag aus dem verwendeten Code und der zufälligen Gerätekennung, die damit verknüpft ist, damit der Code nicht erneut verwendet werden kann. Schreiben Sie an die oben genannte Adresse, und er wird innerhalb eines Monats gelöscht oder Ihnen zugesandt. Das Löschen gibt den Code für jemand anderen wieder frei.

Wenn Sie sich im Vereinigten Königreich befinden, können Sie sich außerdem beim Information Commissioner's Office beschweren.

Diese Website

Diese Website nutzt Google Analytics, um Besuche zu zählen und zu sehen, welche Seiten gelesen werden, sowie Microsoft Clarity, um zu sehen, welche Teile einer Seite gelesen werden und wo Nutzer ins Stocken geraten. Sie sind die einzigen Drittanbieter auf dieser Website, es gibt keine Werbung, und nichts hier wird verwendet, um ein Profil von Ihnen zu erstellen oder Sie andernorts zu verfolgen.

Es wird nichts geladen, bevor Sie zustimmen. Analyse-Cookies sind nicht unbedingt erforderlich, daher benötigen sie nach den Privacy and Electronic Communications Regulations zunächst Ihre Einwilligung. Bei Ihrem ersten Besuch erscheint ein Hinweis mit Akzeptieren und Ablehnen. Bis Sie sich entscheiden, hält der Google Consent Mode jeden Speichertyp auf „verweigert“, und weder das Google- noch das Microsoft-Skript wird überhaupt geladen – wenn Sie also ablehnen, werden keine Cookies gesetzt und beiden wird nichts übermittelt. Ihre Wahl wird im lokalen Speicher Ihres Browsers gespeichert, damit der Hinweis nur einmal erscheint.

Wenn Sie es sich anders überlegen, löschen Sie die Daten dieser Website in Ihrem Browser, und der Hinweis wird wieder angezeigt.

Wenn Sie zustimmen, erhält Google die üblichen Analysesignale – die Seiten, die Sie ansehen, ungefähr wo Sie sich befinden und welche Art von Gerät und Browser Sie verwenden – und setzt Cookies, um einen Besuch vom nächsten zu unterscheiden. Google handelt dabei als Auftragsverarbeiter, und der Umgang mit den Daten richtet sich nach der Datenschutzerklärung von Google. Werbe- und Personalisierungssignale bleiben unabhängig von Ihrer Wahl deaktiviert.

Microsoft Clarity geht über das reine Zählen hinaus. Wenn Sie zustimmen, zeichnet es auf, wie eine Seite während Ihres Besuchs gescrollt und angeklickt wird, und spielt diese Interaktionen erneut ab, und es setzt eigene Cookies, um einen Besuch vom nächsten zu unterscheiden. Alles, was in ein Formularfeld eingegeben oder aus einem Dropdown-Menü ausgewählt wird, wird maskiert, bevor es Ihren Browser verlässt: Clarity maskiert dies in jedem angebotenen Modus und bietet keine Möglichkeit, dies abzuschalten. Bei der hier verwendeten Einstellung werden zudem Zahlen und E-Mail-Adressen, die irgendwo auf der Seite erscheinen, maskiert. Microsoft fungiert dabei als Auftragsverarbeiter, und die Handhabung unterliegt der Microsoft-Datenschutzerklärung. Da die Aufzeichnung eines Besuchs keine aggregierte Information darstellt, darf sie nicht ohne Nachfrage erfolgen – deshalb wird die Wahl angeboten und nicht vorausgesetzt.

Unabhängig davon führt der Hosting-Anbieter übliche Server-Zugriffsprotokolle, was für jede Website normal ist und von Wren weder gelesen noch verwendet wird.

Nichts davon betrifft die App. Wren, die Android-App, enthält keinerlei Analysefunktionen und hat das auch nie getan. Dieser Abschnitt bezieht sich ausschließlich auf diese Website.
