Datenschutz für Android

Zuletzt aktualisiert am 17. August 2026

Die Kurzfassung

Die App hat keine Konten und keine Analyse-Software. Ihre Screenshots und jede Datei, die Sie importieren, werden auf Ihrem Telefon gelesen und niemals hochgeladen. Das Einzige, was sie speichert, ist eine zufällige Kennung für Ihr Gerät, und auch nur dann, wenn Ihnen ein kostenloser Code zur Verfügung gestellt wurde und Sie sich entscheiden, ihn einzugeben — das ist auch der einzige Grund, warum sie mit einem eigenen Server Kontakt aufnimmt.

Diese Website ist eine separate Angelegenheit: Sie verwendet Google Analytics, und nur dann, wenn Sie den Hinweis bei Ihrem ersten Besuch akzeptieren. Wenn Sie ablehnen, werden keine Cookies gesetzt.

Was Wren erfasst

Nichts, mit einer Ausnahme, und nur, wenn Sie es wählen: Die Eingabe eines kostenlosen Codes sendet diesen Code und eine zufällige Kennung für diese Installation an einen von Wren betriebenen Server. Nichts weiter über Sie wird erfasst, gespeichert oder weitergegeben. Kein Konto, keine Anmeldung, keine Analyse, keine Werbekennung, keine Absturzberichte.

Wenn Sie nie einen Code eingeben – und fast niemand tut das, weil Codes an namentlich genannte Personen gehen –, nimmt Wren überhaupt nie von sich aus Kontakt zu einem Server auf.

Ihre Screenshots und importierte Dateien

Wird auf dem Telefon gelesen und nie hochgeladen. Die Texterkennung läuft über ein Modell innerhalb der App selbst, sodass das Lesen eines Screenshots auch bei ausgeschaltetem Netzwerk funktioniert und das Bild Ihr Gerät nie verlässt. Dasselbe gilt für einen CSV-, GPX-, KML- oder Google-Takeout-Export, den Sie importieren.

Was Ihr Gerät verlässt, und wohin es geht

Zwei Dinge, und keines davon ist ein Screenshot.

Das Erste ist der Name eines Ortes und die Stadt, in der Sie ihn bestätigt haben. „Dishoom Shoreditch“ in eine Koordinate zu verwandeln bedeutet, eine Karte zu befragen, und Androids eigener Geocoder antwortet über das Netzwerk – auf den meisten Telefonen ist das Google, gemäß Googles Datenschutzrichtlinie, genau wie bei jeder App, die eine Adresse nachschlägt. Sonst geht nichts mit, und es geht überhaupt nichts, bis Sie eine Suche anfordern.

Die Stadt ist eine, die Sie in der App gewählt haben. Wren fragt nie, wo sich Ihr Telefon befindet – es gibt bewusst keine Standortberechtigung. Es fragt nur, wo sich ein benannter Ort befindet.

Das Zweite ist ein Gutscheincode und eine zufällige Kennung, die im Folgenden beschrieben werden.

Kostenlose Codes

Manchen Personen wird ein Code gegeben, der kostenpflichtige Funktionen freischaltet, ohne dass bezahlt wird. Wird ein Code eingegeben, werden zwei Dinge an einen vom Entwickler betriebenen Cloudflare Worker gesendet: der Code und eine zufällige Kennung für diese Installation. Das Paar wird gespeichert, damit ein Code einmal verwendet werden kann und nicht erneut – das ist der ganze Grund, warum überhaupt ein Server beteiligt ist, da ein Telefon keine Möglichkeit hat zu wissen, ob ein Code bereits auf einem anderen Telefon verwendet wurde.

Die Kennung wird von Wren erzeugt und leitet sich aus nichts ab: nicht aus Ihrer Android-ID, nicht aus der Werbekennung, aus nichts, was mit der Hardware oder Ihrem Konto zu tun hat. Sie identifiziert diese Installation und nichts darüber hinaus. Das Deinstallieren der App entfernt sie, sodass eine neue Installation eine neue Kennung erhält.

Eine kleine Anzahl von Codes gewährt zudem administrativen Zugriff auf die eigene Codekonsole des Entwicklers. Nur diese werden erneut mit dem Server bestätigt, etwa einmal täglich, damit ein solcher Code entzogen werden kann. Eine erneute Bestätigung sendet dieselben zwei Dinge und nichts weiter. Ein gewöhnlicher Code wird einmal geprüft, wenn er eingegeben wird, und danach nie wieder.

Wird ein Code abgelehnt, wird die ursprüngliche IP-Adresse für sich allein bis zu eine Stunde lang erfasst, damit der Endpunkt nicht mit Rateversuchen überhäuft werden kann. Sie wird nicht zusammen mit dem Code oder der Kennung gespeichert, bei einem erfolgreichen Code wird sie überhaupt nicht gespeichert, und sie wird automatisch gelöscht.

Ihre Liste an eine andere Karten-App senden

Die Liste wird in eine Datei auf Ihrem Telefon geschrieben und an die von Ihnen gewählte App übergeben. Diese Übergabe erfolgt lokal: Nichts wird hochgeladen, und Wren ist nicht mehr beteiligt, sobald die andere App die Datei hat.

Google My Maps ist die Ausnahme, die es zu nennen gilt. Wren speichert die Datei über Androids eigenen Speichern-Dialog und öffnet dann google.com/maps/d/ in Ihrem Browser. Was danach geschieht, ist Ihr Browser, in Ihrer eigenen Google-Sitzung – Wren lädt nichts hoch und kann nichts davon sehen.

Berechtigungen

Genau eine: Internetzugriff, benötigt für die Ortssuche und, falls Sie einen eingeben, für den Code. Kein Standort, keine Kamera, keine Kontakte und kein Zugriff auf Dateien außer denen, die Sie ihr über die Systemauswahl übergeben.

Was auf Ihrem Gerät gespeichert wird

Falls Sie einen Gutscheincode eingelöst haben, die signierte Antwort, die dies bestätigt. Das ist es, was Wren erlaubt, Ihren Zugang offline zu prüfen. Und die Liste der Orte, an denen Sie gerade arbeiten, bis Sie sie veröffentlichen oder leeren.

Dies sind gewöhnliche App-Speicherdaten auf Ihrem Telefon, abgedeckt durch die eigene Verschlüsselung Ihres Geräts. Das Löschen von Wren löscht sie.

Instagram und andere Apps

Wren verbindet sich nicht mit Instagram, TikTok oder einem anderen Dienst. Es hat keinen Zugriff auf Ihre Konten dort und liest, durchsucht oder lädt nichts von dort herunter. Es liest nur Screenshots, die Sie selbst aufgenommen und mit ihm geteilt haben.

Kinder

Wren richtet sich nicht an Kinder und erhebt von niemandem, unabhängig vom Alter, personenbezogene Daten.

Ihre Rechte

Nach der britischen DSGVO und der EU-DSGVO haben Sie Anspruch auf Zugang, Berichtigung, Löschung, Einschränkung, Widerspruch und Übertragbarkeit bezüglich der über Sie gespeicherten personenbezogenen Daten.

Wenn Sie noch nie einen kostenlosen Code eingegeben haben, speichert Wren überhaupt nichts über Sie, sodass es praktisch nichts gibt, worauf zugegriffen, was berichtigt oder gelöscht werden könnte. Falls doch, besteht der einzige Eintrag aus dem verwendeten Code und der zufälligen Gerätekennung, die damit verknüpft ist, damit der Code nicht erneut verwendet werden kann. Schreiben Sie an die oben genannte Adresse, und er wird innerhalb eines Monats gelöscht oder Ihnen zugesandt. Das Löschen gibt den Code für jemand anderen wieder frei.

Wenn Sie sich im Vereinigten Königreich befinden, können Sie sich außerdem beim Information Commissioner's Office beschweren.

Diese Website

Diese Website nutzt Google Analytics, um Besuche zu zählen und zu sehen, welche Seiten gelesen werden, sowie Microsoft Clarity, um zu sehen, welche Teile einer Seite gelesen werden und wo Nutzer ins Stocken geraten. Sie sind die einzigen Drittanbieter auf dieser Website, es gibt keine Werbung, und nichts hier wird verwendet, um ein Profil von Ihnen zu erstellen oder Sie andernorts zu verfolgen.

Es wird nichts geladen, bevor Sie zustimmen. Analyse-Cookies sind nicht unbedingt erforderlich, daher benötigen sie nach den Privacy and Electronic Communications Regulations zunächst Ihre Einwilligung. Bei Ihrem ersten Besuch erscheint ein Hinweis mit Akzeptieren und Ablehnen. Bis Sie sich entscheiden, hält der Google Consent Mode jeden Speichertyp auf „verweigert“, und weder das Google- noch das Microsoft-Skript wird überhaupt geladen – wenn Sie also ablehnen, werden keine Cookies gesetzt und beiden wird nichts übermittelt. Ihre Wahl wird im lokalen Speicher Ihres Browsers gespeichert, damit der Hinweis nur einmal erscheint.

Wenn Sie es sich anders überlegen, löschen Sie die Daten dieser Website in Ihrem Browser, und der Hinweis wird wieder angezeigt.

Wenn Sie zustimmen, erhält Google die üblichen Analysesignale – die Seiten, die Sie ansehen, ungefähr wo Sie sich befinden und welche Art von Gerät und Browser Sie verwenden – und setzt Cookies, um einen Besuch vom nächsten zu unterscheiden. Google handelt dabei als Auftragsverarbeiter, und der Umgang mit den Daten richtet sich nach der Datenschutzerklärung von Google. Werbe- und Personalisierungssignale bleiben unabhängig von Ihrer Wahl deaktiviert.

Microsoft Clarity geht über das reine Zählen hinaus. Wenn Sie zustimmen, zeichnet es auf, wie eine Seite während Ihres Besuchs gescrollt und angeklickt wird, und spielt diese Interaktionen erneut ab, und es setzt eigene Cookies, um einen Besuch vom nächsten zu unterscheiden. Alles, was in ein Formularfeld eingegeben oder aus einem Dropdown-Menü ausgewählt wird, wird maskiert, bevor es Ihren Browser verlässt: Clarity maskiert dies in jedem angebotenen Modus und bietet keine Möglichkeit, dies abzuschalten. Bei der hier verwendeten Einstellung werden zudem Zahlen und E-Mail-Adressen, die irgendwo auf der Seite erscheinen, maskiert. Microsoft fungiert dabei als Auftragsverarbeiter, und die Handhabung unterliegt der Microsoft-Datenschutzerklärung. Da die Aufzeichnung eines Besuchs keine aggregierte Information darstellt, darf sie nicht ohne Nachfrage erfolgen – deshalb wird die Wahl angeboten und nicht vorausgesetzt.

Unabhängig davon führt der Hosting-Anbieter übliche Server-Zugriffsprotokolle, was für jede Website normal ist und von Wren weder gelesen noch verwendet wird.

Nichts davon gilt für die App. Die Android-App Wren enthält keinerlei Analysefunktionen und hat das auch nie getan. Dieser Abschnitt bezieht sich nur auf diese Website.
