Datenschutz

Zuletzt aktualisiert am 17. August 2026

Die Kurzfassung

Die App hat keine Konten und keine Analyse. Ihre Screenshots und alle Dateien, die Sie importieren, werden auf Ihrem Telefon gelesen und niemals hochgeladen. Das Einzige, was sie speichert, ist eine zufällige Kennung für Ihr Gerät, und das nur, wenn Ihnen ein kostenloser Code gegeben wurde und Sie sich entscheiden, ihn einzugeben – dies ist auch der einzige Grund, aus dem sie einen eigenen Server kontaktiert.

Diese Website ist eine separate Angelegenheit: Sie verwendet Google Analytics, und nur dann, wenn Sie den Hinweis bei Ihrem ersten Besuch akzeptieren. Wenn Sie ablehnen, werden keine Cookies gesetzt.

Was Wren erfasst

In der App gibt es kein Konto, das erstellt werden müsste, keine Anmeldung, kein Profil und keinen Analyse- oder Absturzberichtsdienst. Fast alles, was Wren sich merkt, befindet sich auf Ihrem Gerät und verschwindet, wenn Sie die App löschen. (Die Website ist anders und wird weiter unten behandelt.)

Die einzige Ausnahme ist eine zufällige Kennung für Ihr Gerät, und diese gilt nur, wenn Sie einen kostenlosen Code eingeben. Sie wird weiter unten vollständig beschrieben. Wrens Datenschutzhinweis im App Store gibt genau dies an – eine Gerätekennung, die für die App-Funktionalität verwendet wird, nicht mit Ihrer Identität verknüpft ist und niemals zur Nachverfolgung genutzt wird – und diese Seite und dieser Hinweis sollen dasselbe sagen.

Kostenlose Codes

Manchen Personen wird ein Code gegeben, der die kostenpflichtige Funktion freischaltet, ohne dass bezahlt werden muss – Prüfer bei Apple und Freunde des Entwicklers. Dies ist der einzige Teil von Wren, der einen von Wren betriebenen Server kontaktiert, und das geschieht nur, wenn Ihnen ein Code gegeben wurde und Sie sich entscheiden, ihn einzugeben. Falls nicht, kontaktiert Wren diesen Server überhaupt nicht.

Wenn ein Code eingegeben wird, werden zwei Dinge gesendet: der Code selbst und eine zufällige Kennung für Ihr Gerät. Die Kennung wird von Wren erzeugt, leitet sich nicht von Ihrer Hardware ab und identifiziert nichts über diese Installation hinaus. Nichts anderes wird mitgesendet – kein Name, keine E-Mail-Adresse, kein Standort, kein Screenshot.

Das Paar wird gespeichert, damit ein Code nur einmal verwendet werden kann — das ist der einzige Grund, warum überhaupt ein Server beteiligt ist: Ein Telefon kann nicht wissen, dass ein Code bereits auf einem anderen Telefon eingelöst wurde. Die Antwort wird geprüft und auf deinem Gerät gespeichert, und für fast alle ist die Sache damit erledigt — die Prüfung findet kein zweites Mal statt. Die Ausnahme sind die wenigen Codes, die zusätzlich administrativen Zugang zur Konsole des Entwicklers gewähren: Diese werden etwa einmal täglich erneut bestätigt, wobei dieselben zwei Angaben gesendet werden und sonst nichts, damit ein solcher Code zurückgezogen werden kann.

Der Server ist ein Cloudflare Worker im eigenen Konto des Entwicklers, und Cloudflare fungiert dabei als Datenverarbeiter. Wird ein Code abgelehnt, wird die Ursprungs-IP-Adresse für sich allein bis zu einer Stunde lang erfasst, damit die Schnittstelle nicht mit Rateversuchen bombardiert werden kann. Sie wird nicht zusammen mit dem Code oder Ihrer Gerätekennung gespeichert, bei einem erfolgreichen Code überhaupt nicht gespeichert, und sie wird automatisch gelöscht.

Ihre Screenshots und importierte Dateien

Sie entscheiden, welche Bilder Wren lesen darf, über Apples eigene Fotoauswahl. Wren hat keinen dauerhaften Zugriff auf Ihre Fotobibliothek – nur auf die Bilder, die Sie ihr übergeben.

Die Texterkennung läuft vollständig auf Ihrem Gerät mit Apples Vision-Framework. Die Bilder selbst werden von Wren niemals hochgeladen, übertragen oder gespeichert. Dasselbe gilt für eine Datei, die Sie importieren – eine Tabelle oder ein Karten-Export wird über Apples Dokumentenauswahl geöffnet, auf dem Gerät gelesen und niemals irgendwohin gesendet. Sobald ein Name aus einem Bild gelesen wurde, hat Wren keine weitere Verwendung dafür und behält keine Kopie.

Diese Website

Diese Website nutzt Google Analytics, um Besuche zu zählen und zu sehen, welche Seiten gelesen werden, sowie Microsoft Clarity, um zu sehen, welche Teile einer Seite gelesen werden und wo Nutzer ins Stocken geraten. Sie sind die einzigen Drittanbieter auf dieser Website, es gibt keine Werbung, und nichts hier wird verwendet, um ein Profil von Ihnen zu erstellen oder Sie andernorts zu verfolgen.

Es wird nichts geladen, bevor Sie zustimmen. Analyse-Cookies sind nicht unbedingt erforderlich, daher benötigen sie nach den Privacy and Electronic Communications Regulations zunächst Ihre Einwilligung. Bei Ihrem ersten Besuch erscheint ein Hinweis mit Akzeptieren und Ablehnen. Bis Sie sich entscheiden, hält der Google Consent Mode jeden Speichertyp auf „verweigert“, und weder das Google- noch das Microsoft-Skript wird überhaupt geladen – wenn Sie also ablehnen, werden keine Cookies gesetzt und beiden wird nichts übermittelt. Ihre Wahl wird im lokalen Speicher Ihres Browsers gespeichert, damit der Hinweis nur einmal erscheint.

Wenn Sie es sich anders überlegen, löschen Sie die Daten dieser Website in Ihrem Browser, und der Hinweis wird wieder angezeigt.

Wenn Sie zustimmen, erhält Google die üblichen Analysesignale – die Seiten, die Sie ansehen, ungefähr wo Sie sich befinden und welche Art von Gerät und Browser Sie verwenden – und setzt Cookies, um einen Besuch vom nächsten zu unterscheiden. Google handelt dabei als Auftragsverarbeiter, und der Umgang mit den Daten richtet sich nach der Datenschutzerklärung von Google. Werbe- und Personalisierungssignale bleiben unabhängig von Ihrer Wahl deaktiviert.

Microsoft Clarity geht über das reine Zählen hinaus. Wenn Sie zustimmen, zeichnet es auf, wie eine Seite während Ihres Besuchs gescrollt und angeklickt wird, und spielt diese Interaktionen erneut ab, und es setzt eigene Cookies, um einen Besuch vom nächsten zu unterscheiden. Alles, was in ein Formularfeld eingegeben oder aus einem Dropdown-Menü ausgewählt wird, wird maskiert, bevor es Ihren Browser verlässt: Clarity maskiert dies in jedem angebotenen Modus und bietet keine Möglichkeit, dies abzuschalten. Bei der hier verwendeten Einstellung werden zudem Zahlen und E-Mail-Adressen, die irgendwo auf der Seite erscheinen, maskiert. Microsoft fungiert dabei als Auftragsverarbeiter, und die Handhabung unterliegt der Microsoft-Datenschutzerklärung. Da die Aufzeichnung eines Besuchs keine aggregierte Information darstellt, darf sie nicht ohne Nachfrage erfolgen – deshalb wird die Wahl angeboten und nicht vorausgesetzt.

Unabhängig davon führt der Hosting-Anbieter übliche Server-Zugriffsprotokolle, was für jede Website normal ist und von Wren weder gelesen noch verwendet wird.

Nichts davon betrifft die App. Wren, die iOS-App, enthält keinerlei Analysefunktionen und hat das auch nie getan. Dieser Abschnitt bezieht sich ausschließlich auf diese Website.
