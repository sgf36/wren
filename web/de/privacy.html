Zuletzt aktualisiert am 4. Oktober 2026

Die Kurzfassung

Die App hat keine Konten. Auf dem iPhone nutzt sie die Software von Meta und TikTok, um zu erfahren, ob Wrens Werbeanzeigen zu Downloads und Käufen führen — im Vereinigten Königreich und in Europa nur, wenn Sie Tracking erlauben —, und Ihre Antwort ändert nichts an der App. Ihre Screenshots und jede von Ihnen importierte Datei werden auf Ihrem Telefon gelesen und niemals hochgeladen. Zwei Dinge erreichen tatsächlich einen von Wren betriebenen Server, und zwar nur, wenn Sie es verlangen: ein kostenloser Zugangscode, falls Ihnen einer gegeben wurde und Sie ihn eingeben; und der Link zu einem Reel oder Beitrag, falls Sie einen zum Lesen mit Wren teilen. Dieser Beitrag wird abgerufen, gelesen und verworfen — nichts davon wird aufbewahrt, weder das Video, noch die Worte, noch die Ortsnamen.

Diese Website ist eine separate Angelegenheit: Sie verwendet Google Analytics, und nur dann, wenn Sie den Hinweis bei Ihrem ersten Besuch akzeptieren. Wenn Sie ablehnen, werden keine Cookies gesetzt.

Was Wren erfasst

In der App gibt es kein Konto zu erstellen, keine Anmeldung und kein Profil. Fast alles, woran sich Wren erinnert, befindet sich auf Ihrem Gerät und verschwindet, wenn Sie die App löschen. (Die Website ist anders und wird weiter unten behandelt.)

Es gibt zwei Ausnahmen. Auf dem iPhone melden die Software von Meta und TikTok App-Installationen, App-Öffnungen und App-Store-Käufe an diese Unternehmen, damit Wren feststellen kann, ob seine Werbeanzeigen wirken; dies wird unter Werbemessung ausführlich beschrieben. Und auf jedem Gerät wird eine zufällige Kennung für Ihr Gerät gesendet, wenn Sie einen kostenlosen Code eingeben. Wrens Datenschutzkennzeichnung im App Store führt beide auf, und diese Seite und jene Kennzeichnung sollen dasselbe aussagen.

Kostenlose Codes

Manche Personen erhalten einen Code, der die kostenpflichtigen Funktionen freischaltet, ohne dass bezahlt wird – Prüfer bei Apple sowie Freunde des Entwicklers. Das geschieht nur, wenn Ihnen ein Code gegeben wurde und Sie sich entscheiden, ihn einzugeben. Falls nicht, nimmt Wren mit diesem Server überhaupt keinen Kontakt auf.

Wenn ein Code eingegeben wird, werden zwei Dinge gesendet: der Code selbst und eine zufällige Kennung für Ihr Gerät. Die Kennung wird von Wren erzeugt, leitet sich nicht von Ihrer Hardware ab und identifiziert nichts über diese Installation hinaus. Nichts anderes wird mitgesendet – kein Name, keine E-Mail-Adresse, kein Standort, kein Screenshot.

Das Paar wird gespeichert, damit ein Code einmal verwendet werden kann und nicht noch einmal — das ist der ganze Grund, warum überhaupt ein Server im Spiel ist: Ein Telefon hat keine Möglichkeit zu wissen, dass ein Code bereits auf einem anderen Telefon verwendet wurde. Die Antwort wird geprüft und auf Ihrem Gerät gespeichert, und für fast alle ist damit die Sache erledigt — die Prüfung findet nicht noch einmal statt. Die Ausnahme sind die wenigen Codes, die zusätzlich administrativen Zugang zur eigenen Konsole des Entwicklers gewähren: Diese werden etwa einmal täglich erneut bestätigt, wobei dieselben zwei Angaben und nichts weiter gesendet werden, damit ein solcher Code widerrufen werden kann.

Der Server ist ein Cloudflare Worker im eigenen Konto des Entwicklers, und Cloudflare fungiert dabei als Datenverarbeiter. Wird ein Code abgelehnt, wird die Ursprungs-IP-Adresse für sich allein bis zu einer Stunde lang erfasst, damit die Schnittstelle nicht mit Rateversuchen bombardiert werden kann. Sie wird nicht zusammen mit dem Code oder Ihrer Gerätekennung gespeichert, bei einem erfolgreichen Code überhaupt nicht gespeichert, und sie wird automatisch gelöscht.

Ihre Screenshots und importierte Dateien

Sie entscheiden, welche Bilder Wren lesen darf, über Apples eigene Fotoauswahl. Wren hat keinen dauerhaften Zugriff auf Ihre Fotobibliothek – nur auf die Bilder, die Sie ihr übergeben.

Die Texterkennung läuft vollständig auf Ihrem Gerät mit Apples Vision-Framework. Die Bilder selbst werden von Wren niemals hochgeladen, übertragen oder gespeichert. Dasselbe gilt für eine Datei, die Sie importieren – eine Tabelle oder ein Karten-Export wird über Apples Dokumentenauswahl geöffnet, auf dem Gerät gelesen und niemals irgendwohin gesendet. Sobald ein Name aus einem Bild gelesen wurde, hat Wren keine weitere Verwendung dafür und behält keine Kopie.

Ein Reel oder Beitrag, den Sie teilen

Dies ist der einzige Teil von Wren, der etwas, das Sie ausgewählt haben, an einen Server sendet, den Wren betreibt, und das geschieht nur, wenn Sie einen Link zu einem Reel oder Beitrag teilen oder einfügen. Wren kann ihn nicht auf dem Telefon lesen: Ein Teilen-Menü übergibt lediglich eine Webadresse, niemals das Video, weshalb das Video von irgendwoher abgerufen werden muss.

Gesendet werden nur der Link und der Nachweis, dass Sie die Funktion gekauft haben. Sonst nichts – kein Name, keine E-Mail-Adresse, kein Standort, kein Screenshot und keine Kennung für Sie. Der Nachweis ist der Kaufbeleg, den der App Store oder Google Play für den Kauf ausgestellt hat und den der Server bei Apple oder Google prüft; ein kostenloser Code funktioniert ersatzweise ebenso.

Der Server – ein Cloudflare Worker im eigenen Konto des Entwicklers – ruft diesen Beitrag ab, lässt ein Sprachmodell die Ortsnamen aus dessen Bildunterschrift oder seinen Bildern lesen, sendet die Namen zurück an Ihr Telefon und verwirft den Rest. Nichts vom Beitrag wird gespeichert: nicht die Adresse, nicht das Video oder die Bilder, nicht die Bildunterschrift, nicht die gefundenen Namen. Ihr Telefon sucht diese Namen anschließend auf dieselbe Weise, wie es einen von einem Screenshot gelesenen Namen nachschlägt.

Es wird ein einziger Eintrag geschrieben, der lediglich festhält, dass dieser eine Kauf eine Einheit seines monatlichen Kontingents verbraucht hat. Er sagt nichts darüber aus, was gelesen wurde. Das Kontingent besteht, weil jedes Lesen Kosten für den Betrieb verursacht, und das Zählen ist der einzige Grund, warum überhaupt etwas gespeichert wird.

An diesem Moment sind zwei weitere Unternehmen beteiligt, und keinem von beiden wird mitgeteilt, wer Sie sind. Ein Dienst namens ScrapeCreators ruft den Beitrag von der Plattform ab, auf der er sich befindet, und speichert unter Umständen für kurze Zeit eine eigene Kopie des Abgerufenen, damit derselbe öffentliche Beitrag nicht zweimal abgerufen wird. Googles Vertex AI betreibt das Modell, das ihn liest; Google erklärt, dass an Vertex AI gesendete Daten nicht zum Training seiner Modelle verwendet werden. Wren steht in keiner Verbindung zu Instagram, TikTok oder YouTube und fragt stets nur nach einem Beitrag, den Sie selbst zum Teilen ausgewählt haben.
