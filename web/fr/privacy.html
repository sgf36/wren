Confidentialité

Dernière mise à jour le 9 octobre 2026

En bref

L'application n'a pas de comptes. Sur iPhone, elle utilise les outils logiciels de Meta et de TikTok pour savoir si les publicités de Wren conduisent à des téléchargements et des achats — au Royaume-Uni et en Europe, uniquement si vous autorisez le suivi — et votre réponse ne change rien dans l'application. Vos captures d'écran et tout fichier que vous importez sont lus sur votre téléphone et ne sont jamais téléversés. Deux éléments atteignent néanmoins un serveur géré par Wren, et uniquement lorsque vous le demandez : un code d'accès gratuit, si l'on vous en a donné un et que vous le saisissez ; et le lien d'un reel ou d'une publication, si vous en partagez un pour que Wren le lise. Cette publication est récupérée, lue puis supprimée — rien n'en est conservé, ni la vidéo, ni le texte, ni les noms de lieux. L'application compte aussi, de façon anonyme, les étapes que les utilisateurs atteignent — ouvrir l'application, importer des lieux, voir un écran d'achat, acheter — sans rien qui vous identifie, vous ou votre téléphone.

Ce site web est une tout autre affaire : il utilise Google Analytics, et seulement si vous acceptez l'avis lors de votre première visite. Si vous refusez, aucun cookie n'est déposé.

Wren est édité par Spencer Fields, entrepreneur individuel établi au Royaume-Uni, à Lytchett House, 13 Freeland Park, Wareham Road, Lytchett Matravers, Poole, BH16 6FA. Pour toute question concernant cette politique, écrivez à Apps [at] spencerfields [dot] com.

Ce que Wren collecte

Dans l'application, il n'y a aucun compte à créer, aucune connexion et aucun profil. Presque tout ce dont Wren se souvient réside sur votre appareil et disparaît lorsque vous supprimez l'application. (Le site web est différent, et est traité plus bas.)

Il existe deux exceptions. Sur iPhone, les logiciels de Meta et de TikTok signalent à ces entreprises les installations de l'application, les ouvertures de l'application et les achats effectués sur l'App Store, afin que Wren puisse savoir si ses publicités fonctionnent ; cela est décrit en détail sous Mesure publicitaire. Et sur tout appareil, un identifiant aléatoire de votre appareil est envoyé si vous saisissez un code offert. L'étiquette de confidentialité de Wren sur l'App Store déclare les deux, et cette page et cette étiquette sont censées dire la même chose.

Par ailleurs, l'application envoie des décomptes anonymes des étapes atteintes par les utilisateurs, décrits sous Décomptes d'utilisation anonymes. Ils ne contiennent rien qui vous identifie, vous ou votre téléphone, et l'étiquette le déclare également.

Codes gratuits

Certaines personnes reçoivent un code qui débloque les fonctionnalités payantes sans paiement — les évaluateurs d'Apple, et les proches du développeur. Cela ne se produit que si l'on vous a donné un code et que vous choisissez de le saisir. Si ce n'est pas le cas, Wren ne contacte jamais ce serveur.

Lorsqu'un code est saisi, deux éléments sont envoyés : le code lui-même, et un identifiant aléatoire pour votre appareil. L'identifiant est généré par Wren, n'est pas dérivé de votre matériel, et n'identifie rien au-delà de cette installation. Rien d'autre ne l'accompagne — ni nom, ni adresse e-mail, ni localisation, ni capture d'écran.

La paire est conservée afin qu'un code puisse être utilisé une fois et pas davantage, ce qui est la seule raison pour laquelle un serveur est impliqué : un téléphone n'a aucun moyen de savoir qu'un code a déjà été utilisé sur un autre téléphone. La réponse est vérifiée et conservée sur votre appareil, et pour presque tout le monde, cela s'arrête là — la vérification n'a pas lieu une seconde fois. L'exception concerne les quelques codes qui accordent également un accès administratif à la console du développeur : ceux-ci sont reconfirmés environ une fois par jour, en envoyant les deux mêmes éléments et rien d'autre, afin qu'un tel code puisse être révoqué.

Le serveur est un Cloudflare Worker dans le compte du développeur lui-même, et Cloudflare agit en tant que sous-traitant de données pour celui-ci. Si un code est rejeté, l'adresse IP d'origine est enregistrée seule pendant une heure au maximum, afin que le point d'accès ne puisse pas être bombardé de tentatives. Elle n'est pas conservée avec le code ou l'identifiant de votre appareil, elle n'est pas conservée du tout lorsqu'un code réussit, et elle est supprimée automatiquement.

Décomptes d'utilisation anonymes

À partir de la version 2.1.9, l'application informe un serveur géré par Wren lorsque vous atteignez certaines étapes : ouvrir Wren pour la première fois, démarrer un import, lire une publication, voir un écran d'achat, appuyer sur un bouton d'achat, l'achat aboutissant ou non, et enregistrer un guide. Chaque message indique l'étape, son type lorsque cela importe (quel produit, par exemple), si le téléphone est un iPhone ou un téléphone Android, la version de l'application et la langue qu'elle affiche.

Rien ne vous identifie, ni vous ni votre téléphone. Il n'existe aucun identifiant d'aucune sorte, rien n'est stocké sur votre téléphone pour le reconnaître à nouveau, et le serveur ne conserve qu'un total cumulé pour chaque étape et chaque jour — ni les messages individuels, ni l'adresse IP d'où ils proviennent. Le développeur utilise ces totaux pour voir à quel moment les utilisateurs cessent d'avancer avant d'acheter, ce qui est la seule raison de leur existence. Ils ne sont partagés avec personne et ne servent pas à la publicité.

Vos captures d'écran, et les fichiers que vous importez

Vous choisissez quelles images Wren peut lire, via le sélecteur de photos propre à Apple. Wren n'a aucun accès permanent à votre photothèque — seulement aux images que vous lui confiez.

La reconnaissance de texte s'exécute entièrement sur votre appareil, à l'aide du framework Vision d'Apple. Les images elles-mêmes ne sont jamais téléversées, transmises ou conservées par Wren. Il en va de même pour un fichier que vous importez — un tableur ou un export de carte est ouvert via le sélecteur de documents d'Apple, lu sur l'appareil, et jamais envoyé où que ce soit. Une fois qu'un nom a été lu à partir d'une image, Wren n'en a plus l'usage et n'en conserve pas de copie.

Un reel ou une publication que vous partagez

C'est la seule partie de Wren qui envoie quelque chose que vous avez choisi à un serveur géré par Wren, et cela ne se produit que lorsque vous partagez ou collez le lien d'un reel ou d'une publication. Wren ne peut pas le lire sur le téléphone : une feuille de partage transmet une adresse web et jamais la vidéo, il faut donc que la vidéo soit récupérée quelque part.

Ce qui est envoyé, c'est le lien, ainsi qu'une preuve que vous avez acheté la fonctionnalité. Rien d'autre — ni nom, ni adresse e-mail, ni localisation, ni capture d'écran, ni identifiant vous concernant. La preuve est le reçu émis par l'App Store ou Google Play pour l'achat, que le serveur vérifie auprès d'Apple ou de Google ; un code gratuit fonctionne à sa place.

Si vous ne l'avez pas acheté, vos trois premières publications sont lues gratuitement. En guise de reçu, Wren envoie l'enregistrement signé d'Apple attestant que votre Apple Account a téléchargé Wren, lequel porte un identifiant qu'Apple attribue à ce téléchargement. Le serveur ne conserve cet identifiant que pour compter les lectures gratuites, afin qu'il y en ait trois par compte plutôt que trois par réinstallation.

Le serveur — un Cloudflare Worker hébergé dans le propre compte du développeur — récupère cette publication, fait lire les noms de lieux dans sa légende ou ses images par un modèle de langage, renvoie les noms à votre téléphone, puis abandonne le reste. Rien concernant la publication n'est conservé : ni l'adresse, ni la vidéo ou les images, ni la légende, ni les noms trouvés. Votre téléphone recherche ensuite ces noms de la même façon qu'il recherche un nom lu sur une capture d'écran.

Une ligne est enregistrée, et elle indique uniquement qu'un achat a consommé une unité de son quota mensuel. Elle ne dit rien sur ce qui a été lu. Le quota existe parce que chaque lecture coûte de l'argent à fournir, et le comptabiliser est la seule raison pour laquelle quoi que ce soit est conservé.

Deux autres entreprises interviennent à ce moment-là, et aucune ne sait qui vous êtes. Un service appelé ScrapeCreators récupère la publication depuis la plateforme où elle se trouve, et peut conserver une copie de ce qu'il a récupéré pendant une courte durée afin de ne pas récupérer deux fois la même publication publique. Vertex AI de Google exécute le modèle qui la lit ; Google indique que les données envoyées à Vertex AI ne servent pas à entraîner ses modèles. Wren n'est affilié ni à Instagram, ni à TikTok, ni à YouTube, et ne demande jamais que la publication que vous avez choisi de partager.

Wren fait de la publicité sur Instagram, Facebook et TikTok. L'application iPhone inclut donc les kits de développement logiciel de Meta et de TikTok. L'application Android n'inclut ni l'un ni l'autre.

Votre adresse IP parvient aux deux entreprises comme c'est le cas pour tout serveur. Rien de ce que vous faites dans Wren n'est envoyé : ni captures d'écran, ni noms de lieux, ni guides, ni fichiers importés.

Instagram et autres applications

Vos droits

En vertu du RGPD britannique et du RGPD européen, vous disposez de droits d'accès, de rectification, d'effacement, de limitation, d'opposition et de portabilité sur les données personnelles vous concernant.

Wren lui-même ne conserve aucune information vous concernant, sauf si vous avez saisi un code offert. Dans ce cas, le seul enregistrement conservé est le code que vous avez utilisé et l'identifiant d'appareil aléatoire qui l'accompagnait, conservés afin que le code ne puisse pas être réutilisé. Écrivez à l'adresse ci-dessus et il sera supprimé, ou vous sera communiqué, sous un mois. Sa suppression libère le code pour quelqu'un d'autre.

Sur iPhone, les données décrites dans Mesure publicitaire sont détenues par Meta et TikTok, et non par Wren, et Wren n'a aucun moyen de les consulter ou de les supprimer pour une personne en particulier. Utilisez les outils propres de Meta et de TikTok pour l'accès et la suppression ; pour empêcher toute collecte future, désactivez le suivi pour Wren dans les Réglages et réinitialisez votre identifiant publicitaire. Si vous résidez au Royaume-Uni, dans l'Espace économique européen ou en Suisse, Wren est responsable conjoint avec TikTok pour la collecte et la mesure décrites à cet endroit : vous pouvez exercer vos droits auprès de l'un ou de l'autre, et si vous écrivez à Wren à ce sujet, Wren transmettra votre demande à TikTok, qui la traitera.

Si vous résidez au Royaume-Uni, vous pouvez également déposer une plainte auprès de l'Information Commissioner's Office.

Par ailleurs, l'hébergeur conserve des journaux d'accès au serveur ordinaires, ce qui est normal pour tout site web et n'est en rien consulté ou utilisé par Wren.
